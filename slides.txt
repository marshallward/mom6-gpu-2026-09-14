Why Blocking?
-------------

.. `do concurrent`` describes dependency structure, but not the "execution geometry"

.. list-table::
   :widths: 40 60

   * - **Compiler view**
     - Smaller, regular kernels are easier to map efficiently

   * - **CPU view**
     - Preserve locality and familiar ``j-k-i`` traversal where useful

   * - **GPU view**
     - Expose larger horizontal work units without changing algorithms

   * - **Model view**
     - Keep solver control flow in ordinary Fortran


Representative Block Kernel
===========================

.. code:: fortran

   do jsb=js,je,njj ; do isb=is,ie,nii
     ! Block size is nii/njj, truncated at the end
     ieb = min(isb + nii - 1, ie)
     jeb = min(jsb + njj - 1, je)
     iie = ieb - isb + 1
     jje = jeb - jsb + 1

     ! Block loops are local
     do concurrent (k=1:nz, jj=1:jje, ii=1:iie)
       i = isb + ii - 1
       j = jsb + jj - 1
       visc_rem(ii,jj,k) = visc_rem_u(i,j,k)
     enddo
   enddo ; enddo


Index Convention
================

.. list-table::
   :widths: 28 72

   * - ``i,j,k``
     - Domain-space index

   * - ``ii,jj,kk``
     - Block-local center index

   * - ``II,JJ,KK``
     - Block-local face index

   * - ``(isb:ieb)``
     - Block start/end bounds

   * - ``(IsbB:IebB)``
     - Face-aligned block start/end

   * - ``(1:nii)``
     - Center-indexed block sizes

   * - ``(1:nIIB)``
     - Face-aligned block sizes


Layout Parameters
=================

.. list-table::
   :widths: 44 56

   * - ``CONTINUITY_NIBLOCK``, ``CONTINUITY_NJBLOCK``
     - Continuity block size in ``i`` and ``j``

   * - ``CONTINUITY_NKBLOCK``
     - Reconstruction block layers

   * - ``CORIOLIS_ADV_NKBLOCK``
     - Coriolis/advection

   * - ``HORVISC_NKBLOCK``
     - Horizontal viscosity

``0`` selects the full local extent in that direction.


Wrapper functions
=================

.. code:: fortran

   subroutine CorAdCalc(...)
     nkk = CS%nkblock
     if (nkk == 0) nkk = GV%ke

     call CorAdCalc_block(..., nkk, ...)
   end subroutine CorAdCalc

   subroutine CorAdCalc_block(...)
     do ksb = 1,nk,nkk
       do kk = 1,nkk
         ! ...
       enddo
     enddo
   end subroutine CorAdCalc_block

Preserve the module API (no changes to RK2, &c)

Programming Model
=================

.. list-table::
   :widths: 20 80

   * - **Fortran**
     - Express independent work with ``do concurrent``

   * - **OpenMP**
     - Manage data lifetime and movement explicitly

   * - **Blocks**
     - Tune locality and concurrency to the target platform

   * - **Validation**
     - Preserve CPU performance and reproducibility while supporting GPUs
